## Безопасность и стоимость

- Перед нетривиальной задачей укажи цель, затрагиваемые файлы, критерии приёмки, способ проверки и приблизительный объём. После этого работай строго в рамках задачи.
- Ни дополнительных функций, ни «заодно» рефакторинга, ни спонтанной генерации графики/музыки/озвучки; платные операции требуют явного разрешения.
- 1 задача → 1 ограниченный PR/изменение → проверка → запрос подтверждения. Не запускай без разрешения циклы «исправлять до победы».
- Не создавать новые глобальные классы, системы, редакторы и плагины до подтверждения необходимости.
- Любая неопределённость в сюжетных ветках, персонаже, длительности, стилистике — вопрос к автору, а не возможность додумать.
- **Нельзя публиковать Steam-билды, оплачивать Steam Direct, входить в Steamworks, загружать ключи или менять права доступа без отдельного подтверждения владельца.**
- Никогда не помещать токены, ключи, пароли, личные данные, учётные данные Steam, PixelLab, Runway и т. д. в файлы и логи репозитория.

## При получении отдельного разрешения на реализацию

- Godot 4.x stable / GDScript, **один 2D-проект сразу для Android и Windows**. **Android — основная тестовая платформа автора (у него нет ПК), Windows — цель для Steam**. Самая ранняя техническая итерация после G1a обязана подготовить доступный для установки APK и Windows EXE через GitHub Actions. Не откладывать Android на финал.
- Сначала минимальный вертикальный цикл, определённый GDD: крыша → разговор → изменение состояния → исход → хаб → сохранение → новый проход. Не начинать с сотен систем.
- Канонические диалоги и исходы берутся из утверждённых текстов; временный текст всегда маркируется `PLACEHOLDER_NON_CANON`.
- Проверки в Godot headless — полезны, но **не доказывают визуальную корректность, работоспособность Windows-экспорта и качество сцен**. Автор проверяет каждую ключевую версию на телефоне через APK; Windows требует отдельного реального ПК для ручного теста. Не утверждать, что игра протестирована на ПК, если это не было сделано.
- CI и версия Godot фиксируются после утверждения; не обещать поддержку Godot 4.7 или конкретного рендера только на основании старого репозитория.
