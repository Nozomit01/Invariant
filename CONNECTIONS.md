# Подключения и инструменты — INVARIANT

**Состояние:** известен репозиторий `Nozomit01/Invariant` и доступ к нему из ChatGPT через GitHub. **Доступ из конкретной задачи Codex нужно проверить отдельно.** Наличие файла в этом ZIP не означает, что Codex автоматически его увидит.

## Сейчас, пока идёт этап 0

1. **GitHub / Codex:** убедиться, что новый репозиторий выбран именно как `Nozomit01/Invariant`. До утверждения этапа 0 Codex занимается только документами.
2. **Документы:** передать содержимое этого ZIP в репозиторий (подробнее в `IMPORT_GUIDE.md`) после согласия автора. Доступ к GitHub не даёт Codex права читать файлы из локального ZIP, пока их не загрузили.
3. **PixelLab:** сервис подключён к ChatGPT, но это **не доказывает**, что PixelLab подключён к Codex Cloud. Для совместимого локального Codex CLI настройка через https://www.pixellab.ai/mcp — отдельно; не помещать API-токен в GitHub. Пока нельзя генерировать платные изображения без отдельного разрешения.
4. **Superpowers / Context7:** дополнительные навыки и актуальная документация. Не обязательны для чтения/согласования GDD; подключение и наличие в Codex зависит от используемого клиента.
5. **Steamworks:** https://partner.steamgames.com/steamdirect — оформляется владельцем лично. Отдельная учётная запись, банковские/налоговые проверки и взнос; документы не считаются поданными, если автор сам их не оформил.
