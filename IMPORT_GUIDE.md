# Как применить ZIP с Android

Этот архив — готовый комплект документов, **не GitHub commit** и не автоматически подключённая база знаний Codex.

## Вариант A — загрузить в GitHub (предпочтительно после утверждения)

1. Распаковать `INVARIANT_CODEX_V4.zip` на телефоне.
2. Открыть https://github.com/Nozomit01/Invariant и убедиться, что выбран `main` (или документационная ветка).
3. Через **Add file → Upload files** загрузить **содержимое** внутренней папки `INVARIANT_CODEX_V4/`, сохранив структуру каталогов. На некоторых мобильных браузерах массовая загрузка папок недоступна; в таком случае использовать режим десктопного сайта или отдельный Git-клиент.
4. Убедиться, что **в корне** репозитория находятся `AGENTS.md` и `README.md`, а `docs/canon/` содержит оба оригинальных документа. Нельзя помещать их все в одну вложенную папку.
5. Дать Codex `prompts/001_REVIEW_DOCS_ONLY.md` только **после** того, как он сможет видеть файлы GitHub. Не начинать с `003_IMPLEMENTATION_ONLY_AFTER_APPROVAL.md`.

## Вариант B — передать через чат Codex

Если твоя версия Codex позволяет прикладывать файлы, передай оба оригинальных MD и нужные производственные файлы из ZIP, попросив провести **только документарный анализ**. Не предполагай, что Codex увидит весь ZIP без его загрузки/распаковки.

## Вариант C — помочь загрузкой здесь

Если в обычном ChatGPT доступна запись в `Nozomit01/Invariant` через GitHub, можно попросить отдельным сообщением: «Загрузи подготовленные документы V4 в новый репозиторий через отдельную ветку; не меняй канон и не создавай код». Подтверждение коммита и PR должно быть явным.

**Первый промпт — аудит документов, НЕ разработка:** `prompts/001_REVIEW_DOCS_ONLY.md`.
