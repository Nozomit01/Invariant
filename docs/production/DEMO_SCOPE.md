# Демоверсия — предварительные границы (на утверждение)

## Обязательное для минимального релизного демо

- Завершённый самостоятельный 2D эпизод на крыше, цель по длительности **15–20 минут** (проверяется реальными плейтестами).
- Героиня говорит и реагирует на действия/молчание/решения игрока; её скрытые состояния узнаются по поведению, а не по полоскам.
- Передвижение/осмысленное действие, возможность уйти, несколько несимметричных ответов.
- **Утверждены две основные концовки демоверсии из GDD: «Прыжок» и «Уход».** Их канонические условия и последствия не переписывать. Третья концовка не входит в обязательный объём; любое расширение — только по новому решению автора.
- **Полноценный хаб между прохождениями из GDD §17 утверждён для демо**: улица возле того же дома; герой стоит и курит; без свободной ходьбы; можно осматривать окружение, доставать физический плеер из сумки, слушать музыку, изучать прогресс и «Воспоминания». Следующее прохождение начинается через естественное действие: бросить/потушить сигарету → войти в дом → открыть дверь крыши. Не заменять хаб экраном меню или сокращённой заставкой.
- Наклейки за **«Прыжок» и «Уход»** появляются на корпусе плеера по правилам GDD §18, без экрана счётчика концовок и названий исходов. Остальные наклейки и открываемое содержание относятся к полной игре.
- Сохранение результатов, наклеек и доступных воспоминаний; повторное прохождение в пределах реально используемого игрового цикла.
- **При первом получении обеих концовок «Прыжок» и «Уход» показывается отдельный экран «Демоверсия завершена»** с благодарностью игроку и просьбой дождаться релиза полной игры. После закрытия этого экрана игрок **возвращается в полноценный хаб**; плеер, доступные воспоминания, прогресс и возможность снова пройти обе концовки остаются доступны без ограничения. Это именно полноэкранная сцена завершения демо, **не маленькое уведомление**. Канонические сюжетные концовки остаются без изменений; экран относится только к демоверсии. Точный текст/графика/способ закрытия — на утверждение автора. Первый показ привязан к факту открытия двух разных концовок, а не к повторным прохождениям.
- Атмосфера: 2D пиксель-арт, ровный читаемый текст, ветер, город, озвучка (если есть согласие/готовые файлы), эмбиент.
- Windows-сборка, запуск и повторный плейтест на реальном Windows-ПК; CI проверки скриптов/экспорта; правообладатель проверяет финал.

## Необязательно для первой демоверсии

True Ending, секретная «не-концовка», весь внутренний мир, многочисленные мини-игры, остальные три основные концовки и связанные с ними наклейки, **полный каталог ещё не созданных воспоминаний и треков**, Steam Achievements/Cloud, Linux и Android. Эти системы **остаются в дизайне полной игры**, а не отменяются.

## Что пока не определено

Какие именно сцены и реплики входят в 15–20 минут, когда показывать первый запуск/глюк, где заканчивается демонстрационный сюжет, какие треки и воспоминания реально доступны после двух исходов; точный текст, оформление и закрытие экрана завершения демо; означает ли «ходить в хабе» свободное передвижение по улице вопреки GDD §17 (пока не менять исходное правило без уточнения автора). **Полноценный хаб уже утверждён, не обсуждать его сокращение без нового решения автора.** Не решать за автора.
