# G1a — запуск минимального проекта

Один полностью 2D-проект Godot Standard / GDScript для Android и Windows.
Стартовая сцена `scenes/start.tscn` показывает только техническую надпись
`G1a: launch check / PLACEHOLDER_NON_CANON`. Игровой логики нет.

## Среда и предварительные настройки

- Для текущей проверки используется установленный **Godot 4.6.3 stable Standard**.
  Указанная в предложении 4.7.2 не проверялась; постоянная версия движка и CI
  этим заданием не утверждаются. Проект использует формат Godot 4.x.
- **320×240 — предварительное разрешение**, не финальное решение автора.
  Масштабирование: `viewport`, сохранение пропорций 4:3, целочисленный масштаб.
- Compatibility, только узлы Control/Label; Android — landscape.
- Базовый ввод: встроенные UI-действия Godot (клавиатура Windows),
  мышь и эмуляция мыши касанием Android. Стартовая надпись не интерактивна;
  игровые действия и экранные контролы не реализованы.

## Запуск и проверка

1. В Godot Project Manager импортировать корневой `project.godot`.
2. Открыть проект и нажать F6 для стартовой сцены или F5 для проекта.
3. Ожидается техническая надпись по центру экрана, без игровых элементов.

Из корня репозитория:

```sh
godot --version
godot --headless --path . --editor --import --quit
godot --headless --path . --quit-after 60
git diff --check
```

Headless проверяет импорт и исполнение, но не внешний вид и не запуск
на целевых устройствах. Реальные команды и их результаты прилагаются в PR.
Для ручного визуального теста нужен редактор с графическим окружением.

APK и EXE в G1a не создаются. Пресеты экспорта, SDK/JDK, подпись и GitHub Actions
относятся к **G1b**, которая требует отдельного разрешения. Проверка на Android
и Windows здесь не выполнялась; готовность этих экспортов не заявляется.
