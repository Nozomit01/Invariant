# G2 — минимальная интерактивная крыша

Godot **4.7.2 Stable Standard / GDScript**. Стартовая сцена:
`scenes/rooftop.tscn`. Все прямоугольники и точка — **PLACEHOLDER_NON_CANON**;
это технический стенд, не художественный дизайн крыши или персонажей.
Ни сюжетных диалогов, ни героини, ни концовок/сохранений/плеера здесь нет.

Один скрипт `scripts/rooftop.gd`: горизонтальное ускорение и торможение,
ограничение центра прямоугольника игрока по X 22–298, одна точка X=236.
При расстоянии до точки не более 26 появляется подсказка; на новое нажатие
действия выводится «Взаимодействие работает». При отходе подсказка и сообщение
исчезают. Управление остаётся доступным во время технического сообщения.

## Управление

- Windows: физические A/D или стрелки влево/вправо; E — взаимодействие.
- Android: удерживать `<` или `>`; возле ромба нажать «Действие» другим пальцем.
  Три встроенные `TouchScreenButton` используют независимые индексы касаний;
  отпускание одной кнопки не отпускает другую. Одновременные направления
  взаимно компенсируются. Перемещение пальца за пределы кнопки отпускает её.
- Сенсорные кнопки также видны в Windows как ориентир для тестовой сцены;
  управление мышью ими в G2 не реализовано.

## Широкий экран

Сохранены предварительные **320×240**, `viewport`, `keep`, integer scaling,
landscape и Compatibility. Кнопки размером 52×40 находятся в области
Y=190–230: левая X=12–64, правая X=72–124, действие X=248–300.
Крыша заканчивается на Y=184, поэтому кнопки не закрывают игрока и точку.
При широком экране 2400×1080 ожидается масштаб 4, поле 1280×960 с боковыми
полями и вертикальным отступом. Проверка геометрии не заменяет оценку
удобства на настоящем телефоне, включая вырезы и системные жесты.

## Проверки

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/g2_rooftop_smoke.gd
godot --headless --path . --quit-after 120
git diff --check
```

Тест использует реальную сцену и события клавиатуры/мультитача без сторонних
зависимостей. Проверяет движение, ускорение/остановку, границы, действие
только вблизи точки, два пальца и независимое отпускание, встречные
направления, геометрию кнопок при 2400×1080. Первое выполнение до реализации
завершилось ожидаемо: `FAIL: G2 rooftop scene does not exist yet`, exit 1.
После реализации первый тест выявил ошибочные числовые коды стрелок.
Единственная исправляющая итерация заменила их на фактические значения
Godot 4.7.2: Left=4194319, Right=4194321. Повторный тест: все проверки PASS,
`G2 smoke failures: 0`, exit 0. Headless-запуск стартовой сцены с
`--quit-after 120`: exit 0, без ошибок/предупреждений в выводе.
Импорт редактором: exit 0; локальное сообщение об отсутствии Android
build-tools относится к окружению без SDK (экспорт выполняется в CI).
Синтаксических ошибок GDScript при импорте нет.

Движок сообщил для 2400×1080: viewport=(320,240), масштаб=(4,4),
смещение=(560,60). Все три кнопки полностью внутри экрана и ниже крыши.
Это headless-проверка геометрии и синтетического ввода, не физический телефон.

## Проверить APK на Android

1. Открыть успешный запуск CI из PR → **Artifacts** →
   `INVARIANT-Android-debug-arm64`, распаковать ZIP и установить APK.
   Используется существующая временная подпись G1b: если APK не обновляется
   поверх старого, сначала удалить старое приложение (его данные удалятся).
2. Должна сразу открыться крыша с надписью `PLACEHOLDER_NON_CANON`.
3. Удержать каждую стрелку: проверить плавный старт/остановку и обе границы.
4. Подойти к ромбу справа, проверить появление подсказки; удерживая движение
   одним пальцем, другим нажать «Действие». Ожидается техническое сообщение.
5. Отпустить только «Действие»: движение должно продолжиться. Затем отпустить
   движение: игрок останавливается. Проверить встречные стрелки двумя пальцами.
6. На широком экране проверить поля 4:3, видимость и доступность всех кнопок;
   кнопки не должны перекрывать игрока/точку или уходить под вырезы/системные зоны.

Физический телефон и Windows-ПК в облачном окружении не тестируются.
После G2 работа останавливается; G3 требует отдельного разрешения.
