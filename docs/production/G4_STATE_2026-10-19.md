## Разрешённый объём — 19 октября 2026

Автор разрешил только G4: компактную отдельную модель Anxiety/Anger/Boredom/
Apathy, смысловые события, технические переходы в G3 и сброс через отдельный
метод. GDD §8, AGENTS.md, CODEX_TASKS.md и код G3 прочитаны.
Одна отдельная ветка и PR без самостоятельного объединения, максимум одна

Канон, прежние решения, сцена крыши, движение/ввод и экспорт не меняются.

## Модель и границы

`scripts/state/run_state.gd` — локальный RefCounted, без глобального класса,
UI, файловой системы, таймеров или singleton. Четыре независимых параметра
инициализированы нулём. Событие меняет только свой параметр:

| Смысловое событие | Единственный параметр |
|---|---|
| `sensitive_topic` — чувствительная тема | Anxiety / тревога |
| `pressure` — давление | Anger / злость |
| `canned_advice` — шаблонное поучение | Boredom / скука |
| `functional_treatment` — отношение как к функции | Apathy / апатия |

Приращение +1 и различение первого/повторного события — **техническая проба,
не утверждённый баланс**. Не добавлены пороги концовок, итоговый рейтинг,
«правильные ответы», автоматическое затухание или связи параметров.
Модель возвращает только код `first` / `repeated`, неизвестное событие —
`ignored` без изменений. `reset()` обнуляет модель. `snapshot()` возвращает
независимую копию только для диагностики/тестов, не для игрового UI.

Отдельного фреймворка событий нет: маленькое соответствие события параметру
и `apply_event()`. Расширение допускает добавление явного нового события
без зависимости от UI. Числа не выводятся в игре, нет шкал и индикаторов.

## Подключение к существующему G3

Данные остаются в `data/dialogue/g3_test_dialogue.gd`. UI сообщает индекс
подтверждённого выбора сигналом `choice_selected`; rooftop.gd применяет
смысловое событие к модели и передаёт текст реакции обратно в UI.
UI не читает параметры модели. Все добавленные строки —
`PLACEHOLDER_NON_CANON`, не реплики девушки и не канонические условия.

Два демонстрационных набора используют прежние кнопки 1/2/3:

| Тестовый набор | Ответ A / 1 | Ответ B / 2 | Молчать / 3 |
|---|---|---|---|
| Первый | чувствительная тема | давление | без события |
| Следующий | шаблонное поучение | отношение как к функции | без события |

После ответа A/B следующий **явный перезапуск разговора** показывает другой
набор, затем наборы повторяются. Текущая техническая причина указана в подписи
кнопки. Молчание не меняет параметры и не переключает набор — это временное
тестовое правило, не утверждение о молчании во всём сценарии.
Повтор одного события вызывает отличающуюся техническую реакцию.

`rooftop.start_new_run()` после готовности сцены обнуляет модель, возвращает
первый тестовый набор и закрывает старый диалог. Вызывается при загрузке сцены.
Обычные start/stop разговора и уход **не сбрасывают** состояние прохождения.
Сохранения, кнопка нового прохождения, хаб и концовки не создавались.

## Проверки

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/g4_state_smoke.gd
godot --headless --path . --script tests/g3_dialogue_smoke.gd
godot --headless --path . --script tests/g2_rooftop_smoke.gd
godot --headless --path . --quit-after 120
git diff --check
```

На официальном Godot `4.7.2.stable.official.ed1daf0bf` тест G4 до реализации
ожидаемо завершился `FAIL: G4 run-state model does not exist yet`, exit 1.
После реализации модель и интеграция прошли с первого запуска, exit 0:
изолированные изменения каждого параметра, повтор, неизвестное событие,
неизменность модели через snapshot, независимость экземпляров,
детерминированное воспроизведение, reset, все четыре события через G3,
разные реакции, нейтральное молчание, сохранение состояния при уходе/
возвращении и сброс при новом прохождении.

Импорт exit 0 без ошибок GDScript; локальное сообщение об отсутствии Android
build-tools относится к окружению без SDK. SDK устанавливается существующим
CI. В G3-тесте две проверки фиксированного текста заменены проверками
завершения выбора: теперь текст зависит от состояния. Точное соответствие
выборов событиям/параметрам проверяет новый интеграционный тест G4.
Проверки движения, молчания, ухода и мультитача G2/G3 сохранены.
Итог локальных проверок: **G4 — 45 PASS, G3 — 40 PASS, G2 — 24 PASS**,
все процессы exit 0. Headless-запуск стартовой сцены `--quit-after 120`:
exit 0 без ошибок/предупреждений. `git diff --check` — без замечаний.
Исправляющих итераций реализации не потребовалось.

## Проверка на телефоне

Скачать APK из успешного CI → Artifacts → `INVARIANT-Android-debug-arm64`,
распаковать и установить. Существующая одноразовая debug-подпись может
потребовать удаления предыдущей установки; её локальные данные удалятся.

У точки справа нажать «Действие», выбрать A/B, вновь открыть разговор:
проверить подписи второго набора. Снова выбрать A/B и повторить событие
первого набора — текст реакции должен отличаться. Отдельно проверить «Молчать»,
свободное движение, отход/возвращение и выбор пальцем при удержании стрелки.
Чисел/шкал на экране быть не должно. Для сброса тестового прохождения можно
полностью закрыть и заново запустить приложение; отдельной кнопки сброса нет.
Физический телефон и Windows-ПК в этом окружении не тестируются.
