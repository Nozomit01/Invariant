## Этап 1 — технический вертикальный цикл (ориентир 26 окт — 22 ноя)

- **Godot 4.x stable, один 2D-проект под Android + Windows с первого шага**; 4:3/масштабирование, клавиатура и сенсорное управление; минимальная тестовая сцена.
- Начало разговора → несколько содержательных реплик/выборов → состояние героини → 1 исход → **техническая заглушка перехода в хаб** → сохранение → новый заход. **Релизный хаб обязательно полноценный по GDD §17–18**, упрощение допустимо только как временный технический срез, не как финальный дизайн.
- Сразу после минимального проекта — Godot headless import/parse и GitHub Actions с **двумя артефактами: Android debug APK и Windows ZIP/EXE**; автор устанавливает APK и проверяет запуск **на своём смартфоне**, а проверку Windows на реальном ПК организуем отдельно.

### Gate 1: реальный непрерывный игровой цикл, не коллекция подсистем.
