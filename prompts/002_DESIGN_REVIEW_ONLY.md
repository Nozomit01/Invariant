# Task 002 — Проверка архитектуры и границ демо, без кода

Выполняй только после ответа автора на ключевые вопросы из Task 001.

Используя канонический GDD, Character Bible и утверждённые поправки, предложи минимальную архитектуру Godot 4.x для первого полного цикла (крыша → разговор → состояние героини → концовка → хаб → сохранение → новый проход). Проверь порядок маленьких задач для Codex, критерии приёмки, риски Steam/Windows и недопущение лишних механик.

Не пиши ни одной строки игрового кода, не создавай сцены, не генерируй графику и не меняй исходный канон. Изменения документации предоставь как предложение для ревью, не коммить без прямого разрешения.
