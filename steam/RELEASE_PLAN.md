# Steamworks — рабочий релизный план, Steam/Windows главный приоритет

**Не является подключённым Steamworks-аккаунтом** и не подтверждает возможность платежей/банковских выплат. Всё требует действий владельца аккаунта.

## До начала публикации

1. Создать/проверить учётную запись Steamworks на https://partner.steamgames.com/steamdirect и реальное имя владельца/организации.
2. Пройти требуемую налоговую и банковскую проверку (важно для возможных ограничений отдельных стран; виртуальная карта сама по себе не решает банковскую часть).
3. Оплатить Steam Direct Fee — текущий ориентир **$100 за приложение**, правила и налоги проверить в Steamworks.
4. Получить App ID основной игры. Основная игра остаётся upcoming/Coming Soon, пока готовится демо.
5. Создать связанную Demo App в Steamworks, отдельный demo App ID и параметры Windows depot/launch.
6. Оформить и опубликовать Coming Soon страницу: реальные скриншоты/трейлер, возрастной/контентный опрос, описания на заявленных языках, прочие обязательные элементы. Учесть проверки магазина/сборки Valve.
7. Подготовить проверенную Windows-сборку, загрузить тестовый depot через SteamPipe/SteamCMD, установить её из клиента Steam и проверить как настоящий игрок.
8. Демоверсия должна быть рассмотрена и опубликована через Steamworks вручную после проверки автором.

## Сроки и ограничения

- Steam Direct имеет обязательные сроки ожидания для новой игры; в инструкциях Steamworks есть минимальное время после оплаты и период публичного Coming Soon. Проверяй актуальную страницу для своего аккаунта, **не планируй оплату в последнюю неделю**.
- Steam Next Fest **22 февраля – 1 марта 2027**. Если автор решит участвовать: регистрация до **10 января 2027 23:59 PST**, основные материалы на review до **8 февраля**, публичное демо к началу **22 февраля 10:00 PST**. Приоритетный review для пресс-показа — **25 января**. Фестиваль доступен лишь соответствующим требованиям играм и не гарантирует продвижения.
- Для фестиваля полная игра должна оставаться невыпущенной; доступность демо сама по себе не заменяет требования к опубликованной странице основной игры.
- **Перенос демо с 27 на 22 февраля не одобрен автоматически.** Это выбор автора.

## Безопасность

- Steamworks/SteamCMD пароли, Guard codes, секреты деплоя — никогда не в GitHub или Codex-промптах.
- Автоматический CI может собирать тестовый ZIP; **публикация Steam-build запрещена без отдельного прямого подтверждения автора**.
- Steamworks SDK/Steam API не обязательны для загрузки обычной Godot Windows-игры; добавить интеграции только при необходимости.
